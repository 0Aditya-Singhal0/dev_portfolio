# Aditya Singhal portfolio

A recruiter-first software engineering portfolio built with React, TypeScript, Vite, Tailwind CSS, and shadcn-style component primitives.

## Run locally

```sh
nub install
nub run dev
```

## Quality checks

```sh
nub run lint
nub run build
```

The résumé served from `public/Aditya-Singhal-Resume.pdf` is the software-engineering version from the source project.
